# Grantee standing register
Every grantee carries a standing in the grantee master. A grantee referred to the
counter-fraud team is marked `under_investigation` and remains in the master so that
historical disbursements stay traceable.

Standing is set by the assurance team on the instruction of the counter-fraud panel. It is
not set by the grants team, and it is not set as a step in clearing an instalment queue.
