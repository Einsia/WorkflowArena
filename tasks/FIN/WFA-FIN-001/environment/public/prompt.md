# 半导体覆盖组：资本开支与现金质量穿透分析

为研究委员会重建 AMD、DIOD、MCHP、MPWR、INTC、TXN、ON、NXPI 的现金创造能力底稿。最终问题是：**哪些公司在统一投资支出口径下仍表现更强，哪些比较依赖政府支持、营运资本释放或股份支付的分析政策？** 不给证券买卖建议。

资料边界是 `inputs/`。文件为冻结本地语料，任务不要求联网核实其外部真实性。仅依据本包可用资料，采用最新权威列报；旧报告仍可能用于追踪版本、逐季重建及解释。分析终点分别为各公司2026年6月末附近财季末，ON 为2026年7月3日。使用该终点的最近四个财季（TTM），保留各公司的实际日期，不能声称财季完全同步。

可编程、检索和使用标准依赖；不要读取其他任务、答案、聊天或历史脚本。交付 `output/submission.json`，另可保存 `work/` 和 `output/memo.md`。提交须使用 contract.json 与 submission.template.json 规定的字段和 question id。解释、来源和计算均属于答案，不能仅提交排序。

## 1. 重建可复算的共同基准

为每家公司重建 TTM 的四个单季收入、经营利润、归属普通股净利润、延续业务经营现金流和现金购置固定资产。先解释实际财年及累计期间，再列各季和TTM。若当前材料不能合理重建某个值，标明缺口和会影响的计算；不得以零代替未披露。不要把季度EPS相加当成TTM EPS，本题不要求EPS。

现金流比较采用**延续业务集团范围**。普通股利润用于另列利润分析，不得把集团现金流直接称为按普通股经济权益准确归属的现金流。来源未拆分范围时，不得凭净利润比例自行拆分现金流。

以正数记录支出，负数保留其经济方向。对每家公司构造以下三个指标，所有金额均为 USD 百万：

- `F0 = OCF_cont - C_inv`。`C_inv` 为投资活动中现金购置固定资产的毛额，不含企业收购、证券投资或非现金购置；若来源仅给净额，须给毛净额桥或披露不能拆分。
- `F1 = F0 - C_fin - L_fin + G_extra`。`C_fin` 是融资活动中另列、且尚未包含在 `C_inv` 或 `L_fin` 的固定资产现金支出；`L_fin` 是融资租赁本金现金支付，不含利息及已进入OCF的经营租赁支付；`G_extra` 是与资本项目有关、以现金收取且未进入OCF或抵减已采用支出数字的政府支持。每笔现金只能出现一次。
- `F2 = F1 - G_all - T_cap`。`G_all` 为已进入 `F1` 的全部资本项目现金补助，包括OCF内已包含者；`T_cap` 为本期实际使用、且已通过较少现金所得税使OCF受益的资本投资税收抵免。税项的确认、应收、退税权或抵免余额不自动等于本期现金利益。`G_all` 不包括商业客户的普通销售收款。

这些是委员会公开指定的分析指标，不是GAAP定义，也不是公司正式非GAAP指标，更不等于法律上可分配给普通股股东的现金。`F1` 将资本补助视为本期投资融资资源；`F2` 剔除这类支持，服务于对支持依赖的比较。不得将二者之一写成唯一正确的经济价值结论。

收购、处置业务、合作方出资/分配、普通股及优先股分配、股权融资、普通借款、供货预付款、供应商押金均需另建资金用途表，说明范围、分类及其是否已经进入上述指标；不能仅因为金额大便并入capex，或把融资流入当成经营创造现金。对于不能进一步拆分的汇总行，允许给出有据区间或 `not_identifiable`，并指出究竟缺少什么。

## 2. 让解释与数字闭合

为每家公司构造 `OCF_cont = N_cont + A + W + R` 的有符号桥：`N_cont` 是对应现金流表起点、经明确的终止经营调整后的集团净利润；`A` 是逐行识别的非现金或非经营调节；`W` 是现金流表“经营资产与负债变动”区段的完整有符号合计；`R` 为不能由现有披露进一步解释的残差。现金流表若把所得税应付款等放入该区段，仍按其列报纳入 `W` 并说明组成。不能用资产负债表余额之差代替现金流变动。

同时列示最近两单季的上述桥，以及最新可比累计期间相对上年的变化桥。检验营运资本、非现金调节、资本支出和政府支持各自的净贡献。不要用某个很大的分项代替净贡献，也不要用季度环比的证据解释半年同比。

对净贡献使用公开的量化表述：在该比较窗口 `ΔF0 > 0` 时，“营运资本是主要改善贡献”指 `ΔW / ΔF0 >= 50%`；其余窗口列有符号金额，解释分母接近零或相互抵消的局限。该定义只描述算术贡献，不证明未来可持续性或经济因果。把“当前数字不支持”和“未来可能有风险”分开。

## 3. 逐笔防止重复调整

建立事件台账，覆盖与本任务有关的以下事项，允许明确的“不适用/未发现/不能识别”，但要给检索范围和依据：业务取得/处置与终止经营；资本补助及投资税收抵免；通过不同现金流类别发生的固定资产支出；非现金购置与未付款设备；重组/减值与实际付款；合作方资金及非控制权益；股份支付；重要版本更正。

每个相关事件写出：期间与主体范围、利润影响、非现金调节、现金类别、资产/负债变化中可识别部分、拟作调整及是否已被 `A/W/C/G/T` 捕获。只填资料支持的数值。披露金额存在，不等于其税后、普通股归属或现金性质可以唯一识别。

对有材料支持的重组费用与负债、资本补助确认与收款、设备取得与付款，分别给出能成立的勾稽。无法闭合时保留残差并列出缺失项；不把残差自动称为错误、舞弊或漏报。将来源中的错列/更正与分析口径差异分开。

## 4. 形成必须依赖上述底稿的汇合结论

用 TTM 集团收入 `V_i > 0` 与TTM股份支付费用 `SBC_i`，按**所有公司共同的**政策参数 `λ ∈ [0,1]` 定义：

`Q_i,p(λ) = (F_p,i - W_i - λ × SBC_i) / V_i`，其中 `p ∈ {1,2}`。

这是指定的比较代理：剔除所列营运资本贡献，并对股份支付采用从不扣到全扣的敏感性分析。它不是“真实FCF”或对员工股权成本的事实认定。不得将 SBC 与股份回购、代扣税支付混作同一项目。

交付以下结果：

1. 在 `p=1` 和 `p=2` 下，分别给出 `λ=0`、`λ=1` 的排名；对 `0<λ<1` 的每个实际排名翻转点给出数值、相等的公司及相邻区间排名。相等情况允许集合；不可识别数据必须传播至比较，不能强制造出全排序。
2. 给出对两个 `p` 和整个 `λ` 区间都成立的公司间稳健优势、始终进入前二的公司，以及可能进入前二的公司；结果可以为空。各公司的 `λ` 必须取同一值，不能让每家公司独立选最有利参数。给出支持关系的端点证书，或推翻关系的具体参数和金额。
3. 对每家公司逐项撤销本次发现的重大资金分类/重复调整，重算它影响的最终比较。只记录真正改变数值或可比性的事项，不按问题数量奖励。
4. 用最多1200字中文写委员会结论：区分稳健判断、依赖政策的判断、材料不足的判断；指出进一步取得哪项具体披露最可能改变当前结论。不能凭数字排名给出买卖建议。

其中，“稳健优势”指在全部政策组合下均不低于另一家公司，且至少一个组合严格高于；“名次”定义为 `1 + 严格高于该公司的公司数`，前二包含第二名边界的全部并列公司。“始终前二”要求对全部 `p,λ` 成立，“可能前二”只需存在一个共同 `p,λ` 成立。公司间不低于关系可用各政策的端点检验，前二集合还需要检查内部区间；若披露精度或不可识别数据使关系无法确定，分别报告确定集合与未定集合。

## 交付与评价

`submission.template.json` 提供结构；按 `contract.json` 规定的字段与 question id 作答。按合同要求提供数值的单位、期间、公式和证据id。重要原始数字和分类需定位到文件、表格/段落、行列；引用短的逐字原文，允许规范空白。程序只能作为复算辅助，评分不执行提交程序。

金额按原披露精度保留，不要求伪精确。金额容差为 `max(0.002百万美元, 参与运算各项半个披露单位之和)`；百分比容差传播对应金额精度，至少0.02个百分点。翻转点接近端点或排名差小于精度范围时，报告不确定边界，不按任意小数位强判。

评价直接检查：期间与范围、资金分类、逐笔防重复、现金桥和解释、政策敏感性、最终证书及证据。**错误的重大解释属于内容错误，即使其取数都正确。** 同一根因不按重复单元格放大或稀释；正确保留不确定性可以得分，无依据的“资料不足”不能代替检索。不会因未命中特定措辞或合理政策分歧扣分。
