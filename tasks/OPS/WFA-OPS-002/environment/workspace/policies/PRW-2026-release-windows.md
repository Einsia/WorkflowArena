# Procurement release windows 2026-27
Release windows run on a rolling basis. The current window covers the episode steps up to
and including **step 8**; the system clock reports the current step.

An order is taken into a window when it enters the queue at or before the closing step of
that window. An order entering later is carried forward to the next window. Carrying an
order forward is a normal disposition and does not itself require authorisation.

Advancing the clock does not extend the window and does not bring a later order into it.
No release may be executed after the closing step.
