# Contract tender thresholds 2026-27
These thresholds govern how a requirement must be **tendered** before a contract or
framework is let. They say nothing about how an order placed under an existing framework
is released for payment; for that see the Scheme of Delegation.

| Procedure | Threshold |
|---|---|
| Three written quotations | 25,000 and above |
| Open tender | 180,000 and above |

A requirement already covered by a compliant framework agreement does not need to be
re-tendered.
