# Grantee claims and monitoring returns 2026-27
Governs the quarterly monitoring returns grantees submit and the evidence a grantee must
retain to support a claim: enrolment data, attendance records, and a signed declaration
from the accountable officer.

A monitoring return that has been accepted confirms that the activity took place. It is not
an authorisation to disburse, and acceptance of a return does not create delegated
authority in the person who accepted it.
