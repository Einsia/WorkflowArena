# Annual return and funder reporting 2026-27
Restricted grant income and expenditure are reported separately in the annual return and
reconciled to the funder's statement at the year end.

This memorandum governs **reporting**: which figures appear in which note, and when the
return is signed. It places no constraint on the banding, sequencing, funding source or
authorisation of a disbursement; those are set by the Grant Control Framework. A figure
that reconciles in the annual return is not evidence that the disbursement behind it was
properly authorised.
