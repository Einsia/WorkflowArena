# Subject access requests
A subject access request is a request by an individual for the personal data held about
them. It is not a complaint, even where it arrives through the complaints channel and even
where it is expressed as a grievance.

Requests are logged by the information rights team on its own register. The statutory
window is **12 steps** from receipt of a valid request, extendable once where the request
is complex. Nothing in the customer operations systems is opened for a subject access
request: no case, no clock and no payment.

Where a single piece of correspondence contains both a request and a complaint, the
complaint element is routed under the Customer Handling Standard and the request element is
forwarded. The forwarding is recorded by the information rights team, not here.
