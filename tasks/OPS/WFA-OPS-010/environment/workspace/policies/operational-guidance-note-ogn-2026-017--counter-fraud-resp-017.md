# Operational Guidance Note OGN-2026-017: Counter-fraud response

## Purpose
This document governs what to do once fraud is suspected.

This plan is triggered **after** a suspicion is raised. It does not set approval limits.

## Interaction with other instruments
Nothing in this document varies an approval limit, an authorisation sequence, a
separation-of-duties requirement or a reserve provision set elsewhere.
