# Audit Recommendation Note ARN-2026-040: VAT treatment

## Purpose
This document governs recoverability of input tax.

This note governs **tax treatment**. It places no constraint on approval or sequence.

## Interaction with other instruments
Nothing in this document varies an approval limit, an authorisation sequence, a
separation-of-duties requirement or a reserve provision set elsewhere.
