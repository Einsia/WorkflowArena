# WFA-3D-009 评分细则（reviewer-only）

每条判定二元，部分满足即否。连续分 = Σ weight×pass（0–100）。组级门槛：B01 失败 → 除 B04/B05/B06/M13/G12 外全部记 0；若顶层集合中命中的单元编号少于 14 个（视为无集合合同）→ 所有 zone_*、integration、change_* 组记 0；B02 其余失败情形只扣 B02 本条。output/scene.blend 缺失或无法打开时 B01 失败并触发上述门槛。由评审模型判定的条目（M13、G12）合计权重 5.77%，其余条目全部由 checks.py 实测。expected_pass 为设计估计，未实测。

容差：尺寸容差 ±3% 或 ±0.10 m 取大者；位置 ±0.15 m；角度 ±2°；计数必须精确；H/D 比 ±4%（7/9/10 互不重叠）。

## 测量口径
- **COL**：柱子 = 名称以 '<ID>_COL' 开头的对象。柱轴 = evaluated 包围盒 XY 中心；柱高 H = 包围盒 z 跨度；下径 D = 在 z_min+f·D_key 处水平截面宽度的最小值（多立克 f=0.10/0.35/0.60，其余 f=0.35/0.60/1.00）；截面宽度 = evaluated 网格各边与该水平面交点在 12 个方向上投影宽度的最大值。柱式由 H/D 判定：7/9/10 ±4%。
- **LEVELS**：标高去重：取单元集合内非 COL/FIG 对象 evaluated 网格（含该单元对象发出的集合实例/几何节点实例，按发出者名称归类）中法向 z>0.99 的面，面中心落在指定区域内，按 z 合并（差 <0.03 m），排除 z≤0.02。
- **STEPS**：台阶级数 = 台阶区域（台基前缘线前方直至铺地，加台基顶前缘内侧 0.5 m 条带）内 LEVELS 去重个数（台基顶面计为最上一级；若最上一级踏面与台基顶同高（图纸画法），二者为同一级）。圆形神庙取台基外环区域。纪念柱取基座外环。讲坛取平台后方区域。
- **RAY**：射线：对每个单元的非 COL evaluated 网格（含其实例几何）建 BVH 后做射线/射线扫描，只计本单元非 COL 网格命中。开洞扫描中只计不触及扫描两端的开口段（建筑端部之外或退进处的空旷不算开洞）。
- **ROOF**：屋面形制：取本单元非 COL 网格中位于檐口标高以上、法向 0.05<n_z<0.98 的面，按水平法向方位聚类（夹角 <20° 视为同簇，面积 <5% 的簇忽略）；1 簇 = shed，2 簇且方位相反 = gable；圆庙：上述面 n_z 标准差 <0.05 = cone，否则 dome。
- **FIG**：人像类型：FIG 对象包围盒水平最大边 ≥ 0.6×高度 = equestrian；≤ 0.5×高度 = standing。
- **SHAPE**：基座形状：非 FIG 网格 XY 凸包；长宽比 = a/b ±5% 且凸包/包围盒面积比 >0.95 → square/oblong（a=b 为 square）；面积比 0.70–0.86 且长宽比 1±0.05 → round。
